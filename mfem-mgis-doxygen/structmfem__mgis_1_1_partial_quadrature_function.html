Detailed Description

quadrature function defined on a partial quadrature space.

A partial quadrature function is movable, but not copyable. Most of the time, the partial quadrature function holds the memory, but the borrow method allows to use externally allocated memory

The main reason for this choice is to force usage of parallel algorithms.
