Detailed Description

This file implements the evaluation of a material property on a batch of points with the primitive of a backend (see MFront/GenericParallel/Batch.hxx). The generated functions only provide the evaluation at one point.

evaluate a material property at the points of a batch with the primitive of a backend. The batch data are checked (see check), and the statistics are reported by the report function of the material property, unless the calling code gave statistics.

Template Parameters
Evaluationevaluation at one point (see PointEvaluator)
Nnumber of arguments
Applycallable object such that apply(s, n, e, h, f) applies the function object f at the n points of a batch with the execution e (see BatchExecution) and reports the statistics in the output status s through the handler h (see StatisticsHandler), and returns the status
Parameters
[out]soutput status
[in]dbatch data
[in]evaluationevaluation at one point
[in]namesnames of the arguments, for the error messages
[in]runtime_checksif false, the runtime checks are disabled: the number of arguments is not checked, and the statistics are neither combined nor reported, the evaluation at one point never reporting an event
[in]report_functionreport function of the material property
[in]applyprimitive of the backend
Returns
the status
