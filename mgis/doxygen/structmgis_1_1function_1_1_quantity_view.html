Detailed Description

template<FunctionConcept FunctionType, ::tfel::math::unit::UnitConcept UnitType>
struct mgis::function::QuantityView< FunctionType, UnitType >

a view returning the values of a function as quantities

A quantity is a scalar value associated with a physical unit. The view is built from a function with exactly one component. Its call operators return the value of the function at a given integration point:

  • a mutable quantity (a qt_ref object of TFEL/Math), referencing the value of the function, for the non constant call operators,
  • a read-only quantity (a const_qt_ref object of TFEL/Math), referencing the value of the function, for the constant call operators.

Only the call operators which match the way the underlying function can be called are available.
