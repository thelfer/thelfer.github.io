Detailed Description

template<LinearFunctionalSpaceConcept Space, FunctionDataLayoutDescription layout = FunctionDataLayoutDescription{}, bool is_mutable = true>
struct mgis::function::FunctionView< Space, layout, is_mutable >

function defined on a space, whose values are stored in an external memory region.

The FunctionView defines a function using an external memory region.

This memory region may contain more data than the one associated with the function as illustrated by the following figure:

|------------------------------------------------------------—| <- Raw data -> |------------------------------------—| <- Data of the first element --> |------------—| | <-function data-> ^ ^ | | data_size | data_stride

The size of all the data (including the one not related to the function) associated with one element of the space is called the data_stride in the FunctionView class.

The size of the data hold by the function per element of the space, i.e. the number of components of the function is given by data_size.

The values of the view can be accessed either with the offset of an integration point, if the space matches the LinearElementSpaceConcept concept, or with the index of a cell and the index of a quadrature point, if the space matches the LinearQuadratureSpaceConcept concept.

A FunctionView is a lightweight view: it can be copied at a negligible cost, as stated by the specialisation of LightweightViewTraits, and it matches the EvaluatorConcept concept: it can be used as an evaluator, which returns constant values.

Template Parameters
Spacetype of the discretization space on which the function is defined, which must match the LinearFunctionalSpaceConcept concept
layoutdata layout description, stating the number of components of the function and the distance between the values of two successive integration points, both of them being known at compile time or only at run time
is_mutableif true, the view allows modifying the values stored in the external memory region, otherwise those values are constant
