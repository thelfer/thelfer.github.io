Detailed Description

template<typename CallableType, EvaluatorConcept SecondEvaluatorType>

struct mgis::function::internals::BinaryOperatorCurrying< CallableType, SecondEvaluatorType >

partial application of a binary operation to the evaluator of its second argument

This helper matches the EvaluatorModifierConcept concept: applying it to the evaluator of the first argument, with operator| for instance, gives the evaluator of the result of the binary operation. Both the callable object and the evaluator of the second argument are stored in the object.
