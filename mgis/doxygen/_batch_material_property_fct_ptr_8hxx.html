 version of the functions generated by the generic-parallel interface for material properties supported by MGIS. It is compared to the version exported by the libraries (<name>_generic_parallel_api_version symbol) when a material property is loaded: any other version is refused. This version and the structures declared in this file are copies of the ones declared in the MFront/GenericParallelMaterialProperty/MaterialProperty.h header of TFEL, with the same members in the same order, so that MGIS does not depend on TFEL at compile time.

typedef struct mgis_mp_BatchOutputStatus mgis_mp_BatchOutputStatus

summary of the evaluation of a material property on a batch of points (copy of the mfront_gpmp_OutputStatus structure of TFEL). The status member is also the value returned by the functions:

  • 0: the result has been evaluated at all points;
  • 1: a bound is violated with the warning policy at some points;
  • -1: a physical bound, or a bound with the strict policy, is violated at some points (the output is NaN at those points);
  • -4: the result is not finite at some points;
  • -5: invalid arguments, nothing was computed;
  • -6: invalid parameters, nothing was computed;
  • -7: runtime error of the backend.

The codes 0, 1, -1 and -4 are the codes of the generic interface at the reported point: the first point where the evaluation failed, otherwise the first point where the result is unreliable.
