apply a function at the points of a batch and report the statistics of the batch.

If the computations are asynchronous, this function returns once they are submitted to the queue. Otherwise, it waits for their completion.

Without statistics given by the calling code, the statistics are held by a block of device memory of a pool of blocks (see StatusBlockPool): no memory is allocated per call. Local statistics are initialized on the host, copied to the block before the computations and copied back once they are completed: the host never accesses the block.

If the function never reports an event (see the hasEvents method of the handler), the statistics are neither combined nor reported, and no block of the pool is used.

Returns
an error message if the computations can't be submitted to the queue of the given policy, a null pointer otherwise

The computations must be executed after the computations already submitted to the queue, which may compute the inputs. This is guaranteed by an in-order queue. With an out-of-order queue, the computations must be synchronous, and the queue is synchronized before them (see apply).
