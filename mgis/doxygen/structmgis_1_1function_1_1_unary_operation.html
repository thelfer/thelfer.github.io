struct mgis::function::UnaryOperation< CallableType, EvaluatorType >

an evaluator applying a unary operation to the values returned by another evaluator

Such an evaluator is usually built with the unary_operation or transform functions, which can either be applied directly to an evaluator or be composed with other modifiers using operator|:

const auto e2 = e | transform([](const real v) { return v * v; });

The callable object is stored in the instance. The number of components of the returned values is the compile-time size of the type returned by the callable, which must thus be known at compile time. Only the call operators which match the way the underlying evaluator can be called are available, as they are inherited from EvaluatorModifierBase.
