Detailed Description

template<typename T, typename Device>
class mfront::generic_parallel::StatusBlockPool< T, Device >

pool of blocks of memory holding the statuses or the statistics of synchronous computations performed on a device.

The kernels only write in a block when an event occurs (failure at a point, bound violated, etc.). When the block is accessible by the host and by the device (managed or shared memory), the host initializes it before the computations and reads it once they are completed: without event, the device does not access the block and no data is transferred between the host and the device.

The blocks are allocated at their first use on a device and reused by the following calls: no memory is allocated per call. A block is used by one call at a time, so that concurrent calls (from several threads or on several queues) are supported. As the copies of the shared data, the blocks are never freed by the pool.
