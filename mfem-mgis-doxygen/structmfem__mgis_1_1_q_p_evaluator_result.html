Detailed Description

structure describing the result of a partial quadrature function evaluator

By essence, a partial quadrature function evaluator may want to return a view to an existing partial quadrature function or create a new one.

The functions fromFunction and fromView were added after Issue 360 that showed that the direct usage of the class constructors can be easily misused due to the implicit conversion of a function into an immutable view, see https://github.com/thelfer/mfem-mgis/pull/361 for details
