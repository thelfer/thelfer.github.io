struct mgis::function::FunctionDataLayout< layout >

a simple data structure describing how the data of a function is mapped in memory

This class gathers the number of components and the stride of the data of a function through the FunctionDataSize and FunctionDataStride base classes, which store those properties at compile time or at run time depending on the value of layout.

Template Parameters
layoutdata layout description. The requires clause states that the data size and the data stride are greater than zero and that the data size is not greater than the data stride when both are known at compile time.
