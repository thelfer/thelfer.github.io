Detailed Description

template<FunctionalSpaceConcept Space, size_type N, bool is_mutable = true>
requires (N > 0)
struct mgis::function::StridedCoalescedMemoryAccessCompositeTensorsView< Space, N, is_mutable >

a strided coalesced memory access view handling several tensorial objects of possibly different types sharing the same set of components

The view is built from a space and an array of values, whose number of values must be equal to N * getSpaceSize(space), as described by the StridedCoalescedMemoryAccessFunctionViewBase class. The values of each component are stored contiguously in a single memory region, in a non interleaved manner: the values of the k-th component start at the offset k * getSpaceSize(space).

The get member function returns, for a given integration point, the tensorial object built from the components with indices from begin to begin + M - 1, M being the number of components of the queried type, as a strided coalesced view whose stride is equal to the size of the space. Several tensorial objects and scalar values may thus be extracted from the same view, provided that their ranges of components do not exceed the N available components, as stated by the requires-clause.

Only the member functions which match the way the space can be addressed are available.
