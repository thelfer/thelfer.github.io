template<ScalarOrTensorConcept ValueType>
struct mgis::function::StridedCoalescedMemoryAccessCompositeTensorsViewMutableValue< ValueType >

traits defining the type used by the StridedCoalescedMemoryAccessCompositeTensorsView class to return a mutable value of the given type

The primary template returns a strided coalesced view of the tensorial type, whose components are stored contiguously in a single memory region, in a non interleaved manner. It is specialized below for scalar values, which are returned by reference.
