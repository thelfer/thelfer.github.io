◆ shallUseBoundaryElementsAPI()

bool mfem_mgis::PartialQuadratureSpace::shallUseBoundaryElementsAPI ( ) const
nodiscardnoexcept
Returns
if one shall iterate on boundary elements

The rationale behind this method is that partial quadrature spaces can be defined on the main mesh or on submeshes.

If a partial quadrature space is defined on a boundary, two cases may happen:

  1. it can be created on the main mesh or a submesh defined on materials. In this case, one shall iterate over boundary elements and use the MFEM API relative to boundary elements (GetNBE, GetBdrElement, etc.)
  2. if a submesh is defined on the boundaries of the main mesh, however, one shall iterate over the elements and use the MFEM API relative to standard elements (GetNE, GetElement, etc.)
