struct mgis::function::BinaryOperationEvaluatorBase< Child, FirstEvaluatorType, SecondEvaluatorType >

a base class to construct an evaluator by applying a binary operation on the results of two evaluators

This class is meant to be used with the curiously recurring template pattern: the child class gives the binary operation through an apply member function taking the values returned by the two evaluators and returning the values of the resulting evaluator.

The call operators of this class forward the values computed by the two evaluators to the apply member function of the child class: only the call operators which match the way both evaluators can be called are available.
