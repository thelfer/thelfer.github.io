Detailed Description

a concept that must satisfy a function

A function is an object which:

  • is defined on a space, i.e. for which the getSpace function is available,
  • provides the number of components of the values it returns through the getNumberOfComponents function,
  • can be called with either an element index, or an element workspace and an element index, or a cell index and a quadrature point index, or a cell workspace, a cell index and a quadrature point index. The value returned is either a scalar value, a std::span or a std::array,
  • is either a lightweight view or provides a view function returning such a view.
