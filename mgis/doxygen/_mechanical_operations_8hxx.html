Detailed Description

File which declares functions computing mechanical quantities (trace, von Mises stress, hydrostatic pressure, eigen values, Cauchy stress) from the tensorial values of a function and returning the result as a new function.

compute the eigen values of the Cauchy stress obtained from the first Piola-Kirchhoff stress and the deformation gradient of a function

The Cauchy stress is first computed from pk1 and F and its eigen values are then evaluated. Both pk1 and F are interpreted as unsymmetric tensors, which requires 3, 5 or 9 components, corresponding to unsymmetric tensors of dimension 1, 2 or 3; pk1 and F must have the same number of components.

Parameters
[in]ctxexecution context used to report the errors
[in]pk1view on the function whose values are the first Piola-Kirchhoff stresses
[in]Fview on the function whose values are the deformation gradients
Returns
the function holding the eigen values or an empty optional if the number of components of pk1 is not compatible with an unsymmetric tensor, in which case an error is reported through the error handler

compute the hydrostatic pressure of the Cauchy stress obtained from the first Piola-Kirchhoff stress and the deformation gradient of a function

The Cauchy stress is first computed from pk1 and F and its hydrostatic pressure, defined as trace(s) / 3, is then evaluated. Both pk1 and F are interpreted as unsymmetric tensors, which requires 3, 5 or 9 components, corresponding to unsymmetric tensors of dimension 1, 2 or 3; pk1 and F must have the same number of components.

compute the eigen values of the symmetric tensorial values of a function

The values of f are interpreted as symmetric tensors, which requires 3, 4 or 6 components, corresponding to symmetric tensors of dimension 1, 2 or 3; the result is a function whose values have as many components as the dimension of the symmetric tensors.

compute the hydrostatic pressure of the symmetric tensorial values of a function

The hydrostatic pressure is defined as trace(s) / 3. The values of f are interpreted as symmetric tensors, which requires 3, 4 or 6 components, corresponding to symmetric tensors of dimension 1, 2 or 3; the result is a scalar valued function.
