Detailed Description

base class of the execution policies of the backends of the generic-parallel interfaces.

A generated function compares the identifier of the policy it receives with the one of its backend, then converts the policy by static_cast (see getBackendExecutionPolicy). A policy whose identifier is not the one of the backend is refused (invalid arguments).

This class is defined by the MFrontGenericParallelRuntime library, which must be linked by the codes creating policies. The generated libraries do not need it.

Note
getIdentifier is declared before the destructor, so that it is the first entry of the table of virtual functions with all the C++ ABIs (a virtual destructor has one entry with the ABI of Visual Studio and two with the Itanium ABI): a policy created by a code compiled by Visual Studio can be checked by a library compiled by MinGW, and the reverse. Published policies are never modified: a new need of a backend is satisfied by a new policy.
