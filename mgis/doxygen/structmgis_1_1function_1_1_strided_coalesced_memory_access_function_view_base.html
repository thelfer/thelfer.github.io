Detailed Description

template<FunctionalSpaceConcept Space, size_type N, bool is_mutable>
requires (N > 0)
struct mgis::function::StridedCoalescedMemoryAccessFunctionViewBase< Space, N, is_mutable >

a class meant to describe a function, each component of which is stored contiguously in non interleaved manner using the following scheme:

| <------- Component 1 ---------> |....| <----- Component Nc ---------> |
+-------++-------++------++-------+----+-------++------++------++-------+
| Elt 1 || Elt 2 || .... || Elt N |....| Elt 1 ||Elt 2 || .... || Elt N |
+-------++-------++------++-------+----+-------++------++------++-------+

Contrary to the CoalescedMemoryAccessFunctionViewBase class, the values of all the components are stored in a single contiguous memory region: the values of the k-th component start at the offset k * getSpaceSize(space), i.e. the stride between the values of two successive components at a given integration point is equal to the size of the space. This allows the class to store only the space and a pointer to the first value.
