Detailed Description

This file selects the runtime of the tests of the generic-parallel interface for material properties (memory holding the data, synchronization, execution policy), shared by the comparison to the generic interface (compare.cxx) and by the test of the runtime checks (test-no-runtime-checks.cxx).

The data are allocated in managed memory if this file is compiled by a CUDA compiler or by a HIP compiler. The HIP runtime is used if the HIP language is enabled or if the MFRONT_GPMP_COMPARE_USE_HIP macro is defined (required on NVIDIA GPUs). If the MFRONT_GPMP_COMPARE_USE_SYCL macro is defined, the data are allocated in shared USM memory (or in host memory if the MFRONT_GPMP_COMPARE_USE_HOST_MEMORY macro is defined) and the computations are performed on the device selected by the default SYCL selector. Otherwise, the data are allocated in host memory.
