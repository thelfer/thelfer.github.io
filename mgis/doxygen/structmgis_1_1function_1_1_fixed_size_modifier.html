Detailed Description

template<EvaluatorConcept EvaluatorType, size_type N>
requires (N > 0)
struct mgis::function::FixedSizeModifier< EvaluatorType, N >

an evaluator returning the values of a function view as a fixed size span or a scalar

The modifier is built from an evaluator with exactly N components. Its call operators return the values computed by the evaluator at a given integration point:

  • a scalar if N is equal to 1,
  • a std::span<const real, N> if N is greater than 1 and the values returned by the evaluator are stored in contiguous memory,
  • a std::array<real, N> otherwise, in which case the values are copied.

Only the call operators which match the way the underlying evaluator can be called are available.
