Detailed Description

base class of the backends of the generic-parallel interfaces.

The computations on a batch are implemented by function templates of the runtime of an interface (MFront/GenericParallelMaterialProperty, namespace mfront::gpmp, for the material properties), which take the primitive of a backend as last argument (see MFront/GenericParallel/Batch.hxx). A backend selects its headers and writes the expression building its primitive.
