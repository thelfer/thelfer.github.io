Detailed Description

template<SpaceConcept SpaceType>
struct mgis::function::SharedSpace< SpaceType >

this class provides a way to encapsulate a space into a sharable object

Such an object behaves exactly as the underlying space (it satisfies the same concepts) except for the areEquivalent function, which only states that two shared spaces are equivalent when they point to the same object.

Template Parameters
SpaceTypetype of the space encapsulated in the sharable object
