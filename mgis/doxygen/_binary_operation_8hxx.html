Detailed Description

This file declares the BinaryOperationModifier and BinaryOperationModifier2 classes, which build a new evaluator by applying a binary operation to the values returned by two existing evaluators, the binary_operation function used to build such evaluators and the predefined modifiers add, substract, multiply, divide, mean_value and inner_product.

partially apply a binary operation to the evaluator of its second argument

creates a binary_operation_modifier from the callable object and applies it to the given evaluator, which is the evaluator of the second argument of the operation

The returned modifier can be applied to the evaluator of the first argument using operator|, as in e1 | binary_operation(c, e2).
