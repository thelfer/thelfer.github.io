◆ PredictionStrategy

enum struct mfem_mgis::PredictionStrategy
strong

strategy used to make a prediction of the solution at the end of the time step

Enumerator
DEFAULT_PREDICTION 

By default, a nonlinear evolution problem uses the solution at the beginning of the time step, modified by applying Dirichlet boundary conditions, as the initial guess of the solution at the end of the time step.

Warning
In mechanics, this may lead to very high increments of the deformation gradients or the strain in the neighboring elements of boundaries where evolving unknowns are imposed.
BEGINNING_OF_TIME_STEP_PREDICTION 

The BEGINNING_OF_TIME_STEP_PREDICTION strategy determines the increment of the unknown \(\Delta\,{u}\) by solving the following linear system:

\[ \mathbb{K}\,\cdot\,\Delta\,\mathbb{u} = \ets{\mathbb{F}_{e}}-\bts{\mathbb{F}_{i}} \]

where:

  • \(\mathbb{K}\) denotes the prediction operator (See PredictionPolicy::prediction_operator)
  • \(\ets{\mathbb{F}_{e}}\) denotes the external forces at the end of the time step.
  • \(\bts{\mathbb{F}_{i}}\) denotes the inner forces at the beginning of the time step.
  • \(\Delta\,\mathbb{u}\) is subject to the increment of the imposed Dirichlet boundary conditions.
Note
Although the wording explicitly refers to mechanics, this equation applies to all physics.
CONSTANT_GRADIENTS_INTEGRATION_PREDICTION 

The CONSTANT_GRADIENTS_INTEGRATION_PREDICTION strategy determines the increment of the unknown \(\Delta\,{u}\) by solving the following linear system:

\[ \tilde{\mathbb{K}}\,\cdot\,\Delta\,\mathbb{u} = \ets{\mathbb{F}_{e}}-\ets{\tilde{\mathbb{F}}_{i}} \]

where:

  • \(\tilde{\mathbb{K}}\) denotes the operator selected by PredictionPolicy::integration_operator.
  • \(\ets{\mathbb{F}_{e}}\) denotes the external forces at the end of the time step.
  • \(\ets{\tilde{\mathbb{F}}_{i}}\) denotes an approximation of the inner forces at the end of the time step computed by assuming that the gradients are constant over the time (and thus equal to their values at the beginning of the time step).
  • \(\Delta\,\mathbb{u}\) is subject to the increment of the imposed Dirichlet boundary conditions.
Note
the behaviour integration allows taking into account:
  • the evolution of stress-free strain (thermal expansion, swelling, etc.),
  • the viscoplastic relaxation of the stress.
Although the wording explicitly refers to mechanics, this equation applies to all physics.

Parameters
[in,out]ctxexecution context
[in]fmutable view
[in]vimmutable view
Returns
true on success, false on failure

Both views must be defined on the same mesh discretization and on the same location, and must have the same number of components. Their partial quadrature spaces may be different:

  • if both spaces are built on the same mesh, they must have the same size, and the values are copied in the order of the integration points.
  • if the spaces are built on different meshes of the mesh discretization (the whole mesh, a submesh of materials or a submesh of boundaries), the values are copied element by element, using MeshDiscretization::getElementsMapping. Matching elements must have the same number of integration points. The copy fails if getElementsMapping fails, e.g. for boundary elements of a submesh of materials not oriented as in the whole mesh. In parallel, this case is collective.

template<bool parallel>

list the elements having degrees of freedom on a boundary

Returns
a vector of pairs associating the index of each element having at least one degree of freedom on the boundary with the local indexes of these degrees of freedom, grouped by component.
Template Parameters
parallelboolean stating if the computation is done in parallel.
Parameters
[in]pnon linear evolution problem
[in]bidboundary identifier
Note
all the elements having a degree of freedom on the boundary are needed, even those touching it only by an edge or a vertex: the inner force at a node is the sum of the contributions of all the elements sharing this node.
in parallel, MFEM gives a boundary element only to the process owning the adjacent element. A process may thus own an element touching the boundary without owning any boundary element. The degrees of freedom of the boundary are therefore marked by GetEssentialVDofs, which synchronizes the markers between the processes sharing them, as MFEM does for essential boundary conditions. This function is thus collective: all processes must call it.
the local indexes follow GetElementVDofs, which groups the degrees of freedom of an element by component whatever the ordering of the space (byNODES or byVDIM).

const MPI_Comm c )
noexcept

gather the error messages of all processes in the context

After this call, the context holds the same error message on all processes:

  • if no process has an error message, the context is left unchanged.
  • if all the processes having an error message have the same one, this message is kept unchanged.
  • otherwise, the error messages are merged and each one is preceded by the rank of the process that registered it. Processes without error message are not listed.
Parameters
[in,out]ctxexecution context
[in]cMPI communicator
Note
this function is collective: it must be called by all the processes of the communicator.

update the implicit gradient regularisation of the given partial quadrature fields on nodes.

For a scalar function \(f\), the implicit gradient regularization \(\bar{f}\) is defined as the solution of:

\[\bar{f}-l^{2}\cdot\Delta\bar{f}=f \]

where \(l\) is a characteristic length.

See Peerlings et al. for details.
