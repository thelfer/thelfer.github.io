 the computations are performed on a device, which may not access the ordinary memory of the host: the fields must be accessible by the device (memory of the device or shared memory). The library can't assume that the device accesses the ordinary memory of the host, even if the device is a CPU (sycl backend without data transfers).

Detailed Description

This file declares the memory spaces in which the fields given to the functions generated by the generic-parallel interfaces must be located, and the memory spaces of the programming models whose target is selected by the compiler.
