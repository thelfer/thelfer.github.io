Detailed Description

This class implements a backend for SYCL programming model.

Options:

  • data_transfer_policy: automatic (or auto, default), the arguments which are not accessible by the device are copied in device memory and the output is copied back, or none, all the arguments and the output are assumed to be accessible by the device.
  • device_stack_size: minimal stack size, in bytes, of the threads of the device when the computations are performed on an NVIDIA GPU through the CUDA runtime (AdaptiveCpp).

◆ handlesDataTransfer()

bool mfront::generic_parallel::material_property::SYCLBackend::handlesDataTransfer ( ) const
overrideprotectedvirtual

return if the backend shall handle the data transfer from a host to a device

If this method returns true, the array of the pointers to the values of the arguments given by the calling code is named mfront_args_host. The backend shall then define an array of pointers named mfront_args. The pointer to the output values given by the calling code is then named mfront_output_host, and the backend shall define a pointer named mfront_output.

If this method returns false, those variables are directly named mfront_args and mfront_output.

Note
by default, no data transfer is handled
