template<typename CallableType, EvaluatorConcept FirstEvaluatorType, EvaluatorConcept SecondEvaluatorType>
struct mgis::function::internals::BinaryOperationModifierBase< CallableType, FirstEvaluatorType, SecondEvaluatorType >

helper base class giving the number of components of the values returned by a binary operation applied to two evaluators

The number of components is the compile-time size of the type returned by the callable when it is called with the values returned by the two evaluators. A static assertion is raised when this number is only known at run time, as evaluators are required to know it at compile time.
