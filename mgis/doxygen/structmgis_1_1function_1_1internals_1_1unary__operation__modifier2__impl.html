Detailed Description

template<typename CallableType>
struct mgis::function::internals::unary_operation_modifier2_impl< CallableType >

a modifier building a UnaryOperation2 from a callable object which is not stored in the modifier

This helper is a stateless type, which allows the predefined modifiers of this file to be defined as constexpr global variables.

CallableTypetype of the unary operation, which must be trivially default constructible
