Detailed Description

a structure defining a mutable field holder

A mutable field holder may be a scalar value, a reference to externally allocated date (std:span case), or values handled internally (std::vector case).

◆ external_storage_hook

std::shared_ptr<void> mgis::behaviour::MaterialStateManager::MutableFieldHolder::external_storage_hook = {}

object calling the clean-up hook of the externally allocated memory referenced by value, if any (see the set functions taking a hook).

This object is shared by the copies of the field holder: the hook is called once, when the last copy is destroyed or no longer refers to this memory. Code replacing value by other values shall reset it.

◆ shall_be_updated

bool mgis::behaviour::MaterialStateManager::MutableFieldHolder::shall_be_updated = true

boolean stating if the values shall be updated by the updateValues which is call by the revert or update functions.

Setting this flag is usefull when the update of the field is already handled.

Warning
shall_be_updated must not be equal to true if the value of the constant (i.e. is of type std::span<const real>)
