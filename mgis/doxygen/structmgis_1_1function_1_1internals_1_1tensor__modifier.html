Detailed Description

template<TensorConcept TensorType>
struct mgis::function::internals::tensor_modifier< TensorType >

modifier exposing the values computed by an evaluator, or the values of a function, as a tensorial object of type TensorType

This is the modifier behind the as_stensor, as_tensor, ... variables defined below. It is stateless, which allows those variables to be defined as constexpr global variables.

TensorTypetype of the tensorial object to be exposed, which must match the TensorConcept concept
