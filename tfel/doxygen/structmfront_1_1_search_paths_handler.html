void mfront::SearchPathsHandler::addMadnexSearchPath ( const std::string & )
static

append a madnex search path

The path has one of the form:

  • <file_path>
  • <file_path>:<mkt>
  • <file_path>:<mkt>:<material_id>

<mkt> can have one of the values material_property (or MaterialProperty), behaviour (or Behaviour) or model (or Model). If <mkt> is empty or not specified, all types of material knowledge are selected.

<material_id> can be a regular expression. <material_id> can also have the special value <none>.

If the material identifier is empty or not specified, only the material knowledge associated with no material is selected, as with <none>. The regular expression .* selects all materials, including the empty one.

std::string mfront::SearchPathsHandler::search ( const std::string & )
staticnodiscard

search a file in the specified paths. The file is searched using the following conventions :

  • search in the current directory.
  • search in the search paths from the most recently declared search path to the older ones.

Search paths declared through the MFRONT_INCLUDE_PATH are stored at the end of the list.
