 GPUStackSize.hxx
 This file declares a function adapting the stack size of the threads of the device to a CUDA or HIP kernel, used by the generic-parallel interface for material properties. This file must be compiled by a CUDA or a HIP compiler. The HIP runtime is used if the hip/hip_runtime.h header has been included before this file or if the HIP language is enabled, the CUDA runtime otherwise.
