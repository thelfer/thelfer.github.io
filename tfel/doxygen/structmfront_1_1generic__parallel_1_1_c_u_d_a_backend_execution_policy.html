bool preserve_stack_size = false
 if true, the stack size of the threads of the device is never modified and an error is reported if it is too small. Otherwise, the stack size is increased if the kernel requires it. The stack size is a property of the context of the device, shared by the whole process (CUDA and HIP runtimes), and costs memory of the device: a code sharing the device with other libraries may set this option.
 
bool asynchronous = false
 if true, the generated function may return before the end of the computations, once they are submitted to the queue of the policy. The calling code then synchronizes the queue before reading the outputs and the statistics. An asynchronous computation requires statistics (invalid arguments otherwise). The stlpar backend, even when it computes on a device, and the sycl backend when it transfers data, compute synchronously.
