◆ external_storage_hook

std::shared_ptr<void> mgis::behaviour::MaterialStateManager::FieldHolder::external_storage_hook = {}

object calling the clean-up hook of the immutable externally allocated memory referenced by the std::span<const mgis::real> alternative, if any (see the set functions taking a hook).

This object is shared by the copies of the field holder: the hook is called once, when the last copy is destroyed or no longer refers to this memory. Code replacing the values without using the assignment operators of this class (emplace for instance) shall reset it.
