Detailed Description

template<FunctionalSpaceConcept Space, TensorConcept TensorType, bool is_mutable = true>
struct mgis::function::CoalescedMemoryAccessTensorView< Space, TensorType, is_mutable >

a coalesced memory access view which acts as a function returning TFEL's tensorial objects

The view is built either from the views of the N scalar components of a tensorial object, N being the number of components of TensorType, or from a space and an array of values split into such views, as described by the CoalescedMemoryAccessFunctionViewBase class. The values of each component are stored contiguously for the different points of the space, so the values of the different components at a given integration point are not contiguous in memory.

The call operators return a tfel::math::CoalescedView of the tensorial type, which gathers the addresses of the values of the components at a given integration point and allows the tensor to be read, or written for mutable views, in a single operation.

Only the call operators which match the way the space can be addressed are available.
