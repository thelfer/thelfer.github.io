Detailed Description

File which defines the concept an evaluator modifier must satisfy, the EvaluatorModifiersGroup class used to combine modifiers and the operator| used to apply them to an evaluator.

applies a group of modifiers to an evaluator

The modifiers are applied in order: the first modifier of the group is applied to the evaluator, the second one to the evaluator resulting from this first modification, and so on.
