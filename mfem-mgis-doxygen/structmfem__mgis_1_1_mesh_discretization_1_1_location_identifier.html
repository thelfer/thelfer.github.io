Detailed Description

a simple structure to store either a material identifier or a boundary identifier.

Note
This identifier must refer to the main mesh. See the getLocationIdentifier in MeshDiscretization for details.
This structure is sortable, and can be used as key in standard associative containers.
this structure may be invalid and works with MGIS's error handling scheme.
