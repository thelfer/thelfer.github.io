Definition Config.hxx:143

type used to store the values of a function

A buffer of dynamic size is a std::vector<real>, whereas a buffer whose size is known at compile time is a std::array<real, Extent>, which avoids a dynamic allocation.

Template Parameters
Extentnumber of values stored in the buffer, dynamic_extent if the size of the buffer is only known at run time
