Detailed Description

template<SpaceConcept Space, std::size_t N>
struct mgis::function::UniformEvaluator< Space, N >

class describing a uniform evaluator, i.e. an evaluator which returns the same value at each integration point of a space

The value is copied when the evaluator is built, so the object it is built from may be destroyed afterwards.

Template Parameters
Spacetype of the space on which the evaluator is defined
Nnumber of components of the returned values, which must be greater than zero
