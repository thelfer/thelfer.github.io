Detailed Description

template<EvaluatorConcept EvaluatorType, ::tfel::math::unit::UnitConcept UnitType>
struct mgis::function::QuantityModifier< EvaluatorType, UnitType >

an evaluator returning the values computed by an evaluator as quantities

A quantity is a scalar value associated with a physical unit. The modifier is built from an evaluator with exactly one component. Its call operators return the value computed by the evaluator at a given integration point:

  • a read-only quantity (a const_qt_ref object of TFEL/Math) referencing the value computed by the evaluator when this value is stored in memory owned by another object,
  • a quantity owning its value (a qt object of TFEL/Math), in which case the value computed by the evaluator is copied.

Only the call operators which match the way the underlying evaluator can be called are available.
