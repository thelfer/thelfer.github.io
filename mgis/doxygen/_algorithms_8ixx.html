assigns the values computed by an evaluator to a function, the evaluation being sequential

implementation of the sequential assign algorithm

The spaces of the function and the evaluator are compared and the number of components of the values returned by both objects is checked to be the same before the values computed by the evaluator are assigned.

Template Parameters
FunctionTypetype of the function argument, which may be a reference type
EvaluatorTypeevaluator type
Parameters
[in]ctxerror handler used to report the errors
[in,out]ffunction assigned
[in]eevaluator providing the values assigned
Returns
true if the assignment succeeded, false otherwise
Note
the values computed by the evaluator are checked with the check function before being assigned. As no execution policy is used, this function can be called in a constexpr context

The error messages "unmatched spaces" and "unmatched number of components" are registered in the error handler when the spaces of the function and the evaluator are not equivalent or when the number of components of the values they return differs. The evaluator is then checked before the values are assigned.
