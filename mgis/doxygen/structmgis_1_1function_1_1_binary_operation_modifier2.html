struct mgis::function::BinaryOperationModifier2< CallableType, FirstEvaluatorType, SecondEvaluatorType >

an evaluator applying a binary operation to the values returned by two evaluators, without storing this operation

This class behaves as BinaryOperationModifier except that the callable object is not stored in the instance: it must be trivially default constructible and a default constructed object is created each time the values are computed. Such a modifier is thus as light as the two underlying evaluators, which allows constexpr modifiers such as add or inner_product to be defined:

const auto e3 = add(e1, e2);
const auto e4 = e1 | add(e2);

The constructor inherited from BinaryOperationEvaluatorBase only takes the two evaluators as arguments.
