 copy a field in device memory if it is not accessible by the device, and make the field refer to the copy. All the values covered by the strides of the field are copied. For an output, only the values of the field are copied back, so that the values of other outputs sharing the same memory (for example, the thermodynamic forces and the internal state variables of a point stored contiguously) are not overwritten.

Detailed Description

copies in device memory of the fields which are not accessible by the device associated with a queue. The outputs must be copied back by calling the copyOutputs method.
