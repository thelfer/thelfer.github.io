create a modifier converting a finite strain tangent operator computed by an evaluator into another kind of tangent operator

definition of the convert_finite_strain_stiffness function declared in MGIS/Function/TFEL/Mechanics.hxx

The conversion is performed by tfel::material::convert<ResultFlag, SourceFlag, N> and generally requires the two deformation gradients and the Cauchy stress at the integration point considered. The returned object is a modifier to be applied, using operator|, to an evaluator returning a tangent operator of kind SourceFlag.

Template Parameters
ResultFlagkind of the tangent operator to be returned
SourceFlagkind of the tangent operator taken as input
DeformationGradientEvaluatorType0type of the evaluator providing the first deformation gradient
DeformationGradientEvaluatorType1type of the evaluator providing the second deformation gradient
CauchyStressEvaluatorTypetype of the evaluator providing the Cauchy stress
Parameters
[in]F0evaluator used to compute the first deformation gradient
[in]F1evaluator used to compute the second deformation gradient
[in]sevaluator used to compute the Cauchy stress
Returns
a modifier converting the tangent operators it is applied to

The space dimension N is deduced from that of the first deformation gradient evaluator; the second deformation gradient and the Cauchy stress must have the same dimension, which is enforced by static_assert.
