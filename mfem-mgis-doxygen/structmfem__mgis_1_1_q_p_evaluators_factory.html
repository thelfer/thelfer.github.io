Detailed Description

abstract factory for quadrature point evaluators

This class is an abstract factory for quadrature point evaluators, i.e. which provides methods to:

  1. register generators of quadrature point evaluators stored by name, material identifier and equivalent partial quadrature space.
  2. handle the generation of evaluators.
