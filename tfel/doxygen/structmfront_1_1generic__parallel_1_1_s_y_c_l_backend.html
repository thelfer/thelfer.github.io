Detailed Description

backend based on SYCL. The points are treated on the device associated with the queue given by the batch data.

Options:

  • data_transfer_policy: automatic (or auto, default), the fields which are not accessible by the device are copied in device memory and the outputs are copied back, or none, all the fields are assumed to be accessible by the device.
  • device_stack_size: minimal stack size, in bytes, of the threads of the device when the computations are performed on an NVIDIA GPU through the CUDA runtime (AdaptiveCpp).
