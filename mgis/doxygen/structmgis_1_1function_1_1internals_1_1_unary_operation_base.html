Detailed Description

template<typename CallableType, EvaluatorConcept EvaluatorType>
struct mgis::function::internals::UnaryOperationBase< CallableType, EvaluatorType >

helper base class giving the number of components of the values returned by a unary operation applied to an evaluator

The number of components is the compile-time size of the type returned by the callable when it is called with the values returned by the evaluator. A static assertion is raised when this number is only known at run time, as evaluators are required to know it at compile time.
