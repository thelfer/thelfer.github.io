Detailed Description

template<FunctionalSpaceConcept Space, size_type N, bool is_mutable = true>
requires (N > 0)
struct mgis::function::ScatteredMemoryAccessCompositeTensorsView< Space, N, is_mutable >

a scattered memory access view handling several tensorial objects of possibly different types sharing the same set of components

The view is built either from the views of the N scalar components or from a space and an array of values split into such views, as described by the ScatteredMemoryAccessFunctionViewBase class. The values of each component are stored contiguously for the different points of the space, so the values of the different components at a given integration point are not contiguous in memory.

The get member function returns, for a given integration point, the tensorial object built from the components with indices from begin to begin + M - 1, M being the number of components of the queried type. Several tensorial objects and scalar values may thus be extracted from the same view, provided that their ranges of components do not exceed the N available components, as stated by the requires-clause.

Only the member functions which match the way the space can be addressed are available.

Template Parameters
Spacefunctional space on which the view is defined
Nnumber of components, which must be strictly positive
