Detailed Description

template<FunctionalSpaceConcept Space, TensorConcept TensorType>
requires (LinearElementSpaceConcept<Space> || LinearQuadratureSpaceConcept<Space>)
struct mgis::function::TensorialFunction< Space, TensorType >

default implementation of a function whose values are TFEL's tensorial objects

A TensorialFunction stores its values in a Function, whose number of components is the minimal size of the array of values required to store a TensorType, as computed by the tfel::math::getUnderlyingArrayMinimalSize function, and derives from the corresponding TensorView, so it can be called like a function and returns its values as tensorial objects viewing its storage.

Template Parameters
Spacetype of the functional space
TensorTypetype of the tensorial objects returned by the function, which must match the TensorConcept concept
Note
the data stride is equal to the data size
