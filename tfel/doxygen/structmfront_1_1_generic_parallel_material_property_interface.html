static void writePointEvaluation (std::ostream &, const MaterialPropertyDescription &, const PointEvaluationOptions &)
 write the code evaluating a material property at a point, shared by the generic, cyrano and generic-parallel interfaces: physical bounds of the inputs, bounds of the inputs, body of the material property, physical bounds and bounds of the output. The variables are checked in the order of the inputs, the output being the last one. The physical bounds always make the evaluation fail. The bounds make it fail with the strict policy, and are reported with the warning policy: as with the generic interface, an unknown policy is treated as the None policy. The checks are disabled by the given macro, or not written if the runtime checks are disabled. The variables (inputs, parameters, output) and the out of bounds policy (mfront_out_of_bounds_policy) must be declared by the caller.

Detailed Description

the generic-parallel interface for material properties, built on the generic interface: the code evaluating a material property at a point is written by GenericMaterialPropertyInterfaceBase (see writePointEvaluation), the backends writing the batch function and its kernels.
