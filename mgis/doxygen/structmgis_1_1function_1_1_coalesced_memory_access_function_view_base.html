Detailed Description

template<FunctionalSpaceConcept Space, size_type N, bool is_mutable>
requires (N > 0)
struct mgis::function::CoalescedMemoryAccessFunctionViewBase< Space, N, is_mutable >

base class for views whose components are stored contiguously in separate memory regions

Each component is described by a scalar function view whose data are stored contiguously for the different points of the space, as illustrated by the following scheme:

| <------- Component 1 ---------> |....| <----- Component N ---------> |
+-------++-------++------++-------+----+-------++------++------++-------+
| Elt 1 || Elt 2 || .... || Elt N |....| Elt 1 ||Elt 2 || .... || Elt N |
+-------++-------++------++-------+----+-------++------++------++-------+

The values of the different components at a given integration point are not contiguous: the getValuesPointers function gathers the addresses of those values, which allows the values of all the components at a given integration point to be read or written in a single operation. This scheme is used by the CoalescedMemoryAccessTensorView class to map tensorial objects whose components are stored in separate contiguous memory regions.

Template Parameters
Spacetype of the space on which the views are defined
Nnumber of components, which must be strictly positive
is_mutableboolean stating if the view can return mutable pointers
