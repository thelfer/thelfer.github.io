template<typename ForwardIterator>
TFEL_FSALGORITHM_INLINE ForwardIterator tfel::fsalgo::min_element< N >::exe ( ForwardIterator p)
inlinestatic

It returns the first iterator i in [first, first+N) such that no other iterator in [first, last) points to a value smaller than *i. The return value is first+N if and only if [first, last) is an empty range.
