bool mfront::generic_parallel::setMinimalCUDAStackSize ( const std::size_t  stack_size,
const bool  preserve = false 
)
inlinenoexcept

increase the stack size of the threads of the current CUDA device, if the CUDA runtime is loaded by the process. Otherwise, the computations are not performed on an NVIDIA GPU through the CUDA runtime and nothing is done.

Some parallel programming models execute the computations on NVIDIA GPUs through the CUDA runtime but give no access to the stack size of the threads: the C++ standard parallelism with nvc++ -stdpar=gpu and SYCL with AdaptiveCpp. The default stack size (1024 bytes) and the automatic increase performed by the CUDA driver at kernel launch, which does not take into account the internal routines of the compilers (such as the division of double precision numbers), are not sufficient for some kernels.

The CUDA runtime is looked up among the loaded libraries, so that this function does not require the CUDA headers nor the CUDA runtime.

Returns
true on success, false if the stack size could not be set or is too small and must be preserved
Parameters
[in]stack_sizeminimal stack size, in bytes
[in]preserveif true, the stack size is only checked
