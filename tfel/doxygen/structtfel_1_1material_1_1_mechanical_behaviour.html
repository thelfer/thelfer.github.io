Parameters
[in]dtcurrent time step scaling factor
Returns
a pair containing:
  • a boolean syaing if the behaviour integration shall be considered a success or a failure
  • a scaling factor that can be used to:
    • increase the time step if the integration was successfull
    • decrease the time step if the integration failed or if the results were not reliable (time step too large).

Behaviours which are not able to give such a time step scaling factor may return the NumType(1) value.

pure virtual
Parameters
[in]dttime step scaling factor proposed by the calling code
Returns
a pair containing:
  • a boolean syaing if the behaviour integration shall be performed
  • a scaling factor that can be used to:
    • increase the time step if the integration was successfull
    • decrease the time step if the integration failed or if the results were not reliable (time step too large).

Interfaces to behaviour law shall use the hasAPrioriTimeStepScalingFactor member of the specialisation of the traits class MechanicalBehaviourTraits generated by MFront to know if the behaviour is able to give such a time step scaling factor. If not, behaviours may return the NumType(1) value.
