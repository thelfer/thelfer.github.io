Detailed Description

template<typename Statistics, typename PointFunction>
struct mfront::generic_parallel::sycl::internals::Kernel< Statistics, PointFunction >

kernel applying a function at one point and updating the statistics of the batch.

The statistics are updated by atomic operations, which are only performed if an event occurs at this point (see updateStatistics). Parallel reductions are not used since their synchronisation barriers make the compilation of large kernels fail with AdaptiveCpp on CPUs.
