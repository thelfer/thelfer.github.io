Detailed Description

This intermediate class helps implementing various closely related backends which define the kernel as a lambda function. Those backends include ParallelSTL and SYCL

write the code transferring the data to the device

This method is only called if the handlesDataTransfer method returns true. This method shall define mfront_args, an array of pointers to the values of the arguments accessible by the device, and mfront_output, a pointer to the output values accessible by the device. All memory allocated on the device shall be handled by RAII.
