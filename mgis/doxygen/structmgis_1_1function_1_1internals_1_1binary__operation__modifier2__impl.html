Detailed Description

template<typename CallableType>
struct mgis::function::internals::binary_operation_modifier2_impl< CallableType >

helper applying a binary operation which is not stored in the helper to one or two evaluators

This helper behaves as binary_operation_modifier except that it is a stateless type: the binary operation is created when the values are computed, which allows the predefined modifiers of this file to be defined as constexpr global variables.

Template Parameters
CallableTypetype of the binary operation, which must be trivially default constructible
Note
this helper does not match the EvaluatorModifierConcept concept itself: its single argument call operator returns such a modifier
