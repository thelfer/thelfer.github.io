Detailed Description

a concept that must satisfy an evaluator

An evaluator is an object which:

  • can be moved and copied,
  • is defined on a space, i.e. for which the getSpace function is available,
  • provides the number of components of the values it returns through the getNumberOfComponents function,
  • can check the values it computes through the check function,
  • can be called with either an element index, or an element workspace and an element index, or a cell index and a quadrature point index, or a cell workspace, a cell index and a quadrature point index. All the valid calls return the same type.

Contrary to a function, an evaluator is called with a constant object and returns constant values.
