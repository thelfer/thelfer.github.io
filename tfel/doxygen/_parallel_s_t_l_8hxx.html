apply a function at the points of a batch and report the statistics of the batch. This function waits for the completion of the computations. The statistics given by the calling code, if any, are accumulated on the host. If the function never reports an event (see the hasEvents method of the handler), the statistics are neither combined nor reported.

Template Parameters
device_stack_sizeminimal stack size, in bytes, of the threads of the device when the parallel algorithms are offloaded to an NVIDIA GPU by nvc++ -stdpar=gpu (see mfront::generic_parallel::setMinimalCUDAStackSize). The stack size is not modified if this value is null. This value is a template argument so that the code setting the stack size, which looks for the CUDA runtime with the functions of the dynamic loader, is only compiled if required.
