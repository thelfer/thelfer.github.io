Detailed Description

template<FunctionConcept FunctionType, TensorConcept TensorType>
struct mgis::function::TensorView< FunctionType, TensorType >

an evaluator returning the values of a function as TFEL's tensorial objects

The view is built from a function whose number of components must be equal to the number of components of TensorType. Its call operators return the values of the function at a given integration point, mapped on the memory of the function using tfel::math::map:

  • a read-only tensor, for the constant call operators,
  • a mutable tensor, which may be modified, for the non constant call operators.

Only the call operators which match the way the underlying function can be called are available.
