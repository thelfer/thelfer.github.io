Detailed Description

Declaration of the algorithms which can be applied to the functions and the evaluators of the MGIS/Function library, that is assign and scalar_reduce, and of the helpers used to check if an evaluator can be assigned to a function.

assigns the values computed by an evaluator to a function, the evaluation being sequential

implementation of the sequential assign algorithm

The spaces of the function and the evaluator are compared and the number of components of the values returned by both objects is checked to be the same before the values computed by the evaluator are assigned.

Template Parameters
FunctionTypetype of the function argument, which may be a reference type
EvaluatorTypeevaluator type
Parameters
[in]ctxerror handler used to report the errors
[in,out]ffunction assigned
[in]eevaluator providing the values assigned
Returns
true if the assignment succeeded, false otherwise
Note
the values computed by the evaluator are checked with the check function before being assigned. As no execution policy is used, this function can be called in a constexpr context

The error messages "unmatched spaces" and "unmatched number of components" are registered in the error handler when the spaces of the function and the evaluator are not equivalent or when the number of components of the values they return differs. The evaluator is then checked before the values are assigned.

reduces the values computed by a scalar evaluator to a single value using the given reduction operator, the evaluation being sequential

implementation of the sequential scalar_reduce algorithm

The values computed by the evaluator are checked before being reduced.

Template Parameters
EvaluatorTypeevaluator type
OperatorTypetype of the reduction operator, a binary operation taking two scalar values and returning a scalar value
Parameters
[in]ctxerror handler used to report the errors
[in]eevaluator reduced
[in]opreduction operator
[in]initial_valuevalue the reduction starts from
Returns
the reduced value or an empty std::optional if an error is reported
Note
this function requires the values returned by the evaluator to have a single component

The error message "non scalar evaluator" is registered in the error handler when the values returned by the evaluator have more than one component. The evaluator is then checked before being reduced.
