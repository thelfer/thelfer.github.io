Detailed Description

template<typename CallableType>
struct mgis::function::internals::binary_operation_modifier< CallableType >

helper applying a stored binary operation to one or two evaluators

The binary operation is stored in the helper. Calling the helper with the evaluator of the second argument only gives a BinaryOperatorCurrying object, i.e. a modifier which is applied to the evaluator of the first argument. Calling the helper with the two evaluators gives the evaluator of the result of the binary operation.

Template Parameters
CallableTypetype of the binary operation, which must be copy constructible
Note
this helper does not match the EvaluatorModifierConcept concept itself: its single argument call operator returns such a modifier
