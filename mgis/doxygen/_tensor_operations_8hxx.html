Detailed Description

File which declares functions rotating the tensorial values of a function into another basis and returning the result as a new function.

Enumeration Type Documentation

◆ RotationOperation

enum struct mgis::function::RotationOperation
strong

supported rotation operations

  • If the rotation operation is FORWARD, the given rotation matrix is used directly.
  • If the rotation operation is BACKWARD, the transposed of the rotation matrix is used.

◆ TensorType

enum struct mgis::function::TensorType
strong

type of tensor that are supported

  • STENSOR designates a symmetric tensor,
  • TENSOR designates an unsymmetric tensor,
  • ST2TOST2 designates a fourth order tensor mapping symmetric tensors to symmetric tensors.

rotate the values of a function seen as fourth order tensors mapping symmetric tensors to symmetric tensors and return the result as a new function

The number of components of s must be 9, 16 or 36, corresponding to fourth order tensors of dimension 1, 2 or 3. The rotation matrix is taken from the r view, which must have 9 components.

Parameters
[in]ctxexecution context used to report the errors
[in]sview on the function whose fourth order tensorial values are rotated
[in]rview on the function whose values are the rotation matrices
[in]rorotation operation to be performed
Returns
the function holding the rotated values or an empty optional if the inputs are inconsistent, in which case an error is reported through the error handler

rotate the tensorial values of a function and return the result as a new function

The type of the tensorial objects handled is given by the type argument and the rotation is performed with the rotation matrix given by the r view. The number of components of t must be compatible with type: 3, 4 or 6 components for a symmetric tensor, 3, 5 or 9 components for an unsymmetric tensor and 9, 16 or 36 components for a fourth order tensor st2tost2.

Parameters
[in]ctxexecution context used to report the errors
[in]tview on the function whose values are rotated
[in]rview on the function whose values are the rotation matrices, which must have 9 components
[in]typetype of the tensorial objects handled by the function
[in]rorotation operation to be performed
Returns
the function holding the rotated values or an empty optional if the inputs are inconsistent, in which case an error is reported through the error handler
