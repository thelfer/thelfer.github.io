alias of the single argument unary_operation function

This function is an alias of the unary_operation function, which is often more readable when the operation is a user defined lambda:

create a modifier applying a unary operation to the values returned by an evaluator

creates a modifier storing a copy of the given callable

The returned modifier can be applied to an evaluator using operator| or composed with other modifiers, as in e | unary_operation(c1) | unary_operation(c2).
