Detailed Description

template<MathObjectConcept Type>
struct tfel::math::TypeRebind< Type >

this struct exposes standard types compatible with its argument.

  • the exposed types have the same space dimension at the argument
  • the exposed types use quantities if the argument does.

A typical usage of this class is to deduce the types of the arguments of a method from the type of one of the argument.
