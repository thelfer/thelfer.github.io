 CoalescedMemoryAccessTensorView.ixx
 File which contains the implementation of the CoalescedMemoryAccessTensorView class declared in MGIS/Function/TFEL/CoalescedMemoryAccessTensorView.hxx.
 
 DataView.hxx
 This file specializes the IsDataView class for TFEL's types, which all view values owned by other objects.
 
 General.hxx
 File which gathers the common definitions used to integrate TFEL's types with the functions of the MGIS/Function framework. It currently includes the specialisations of the IsDataView traits for TFEL's types.
 
 MechanicalOperations.hxx
 File which declares functions computing mechanical quantities (trace, von Mises stress, hydrostatic pressure, eigen values, Cauchy stress) from the tensorial values of a function and returning the result as a new function.
 
 Mechanics.hxx
 File which defines the mechanical operations which can be applied to evaluators returning tensorial values (hydrostatic_stress, vmis, principal_stress, from_pk1_to_cauchy, ...) and the convert_finite_strain_stiffness function converting finite strain tangent operators from one kind to another.
 
 Mechanics.ixx
 Implementation of the finite strain tangent operator conversion declared in MGIS/Function/TFEL/Mechanics.hxx: the ConvertFiniteStrainStiffnessEvaluator evaluator, the associated modifier generator and the convert_finite_strain_stiffness function.
 
 Quantity.hxx
 File which defines the concepts and the modifiers used to handle the values of a function or an evaluator as TFEL's quantities, i.e. scalar values associated with a physical unit.
 
 QuantityModifier.hxx
 File which defines the QuantityModifier class, an evaluator returning the values computed by an evaluator with one component as TFEL's quantities, i.e. scalar values associated with a physical unit.
 
 QuantityModifier.ixx
 File which contains the implementation of the QuantityModifier class declared in MGIS/Function/TFEL/QuantityModifier.hxx.
 
 QuantityView.hxx
 File which defines the QuantityView class, a view returning the values of a function with one component as TFEL's quantities, i.e. scalar values associated with a physical unit.
 
 QuantityView.ixx
 File which contains the implementation of the QuantityView class declared in MGIS/Function/TFEL/QuantityView.hxx.
 
 StridedCoalescedMemoryAccessCompositeTensorsView.hxx
 File which defines the StridedCoalescedMemoryAccessCompositeTensorsView class, a view handling several tensorial objects of possibly different types sharing the same set of components, whose values are stored contiguously in a single memory region, in a non interleaved manner.
 
 StridedCoalescedMemoryAccessCompositeTensorsView.ixx
 File which contains the implementation of the StridedCoalescedMemoryAccessCompositeTensorsView class declared in MGIS/Function/TFEL/StridedCoalescedMemoryAccessCompositeTensorsView.hxx.
 
 StridedCoalescedMemoryAccessTensorView.hxx
 File which defines the StridedCoalescedMemoryAccessTensorView class, a view which acts as a function returning TFEL's tensorial objects whose components are stored contiguously in a single memory region, in a non interleaved manner.
 
 StridedCoalescedMemoryAccessTensorView.ixx
 File which contains the implementation of the StridedCoalescedMemoryAccessTensorView class declared in MGIS/Function/TFEL/StridedCoalescedMemoryAccessTensorView.hxx.
 
 TensorConcept.hxx
 File which defines the concepts describing TFEL's tensorial values and the specialisations of the CompileTimeSize and IsTensor helpers for TFEL's fixed size tensorial types.
 
 TensorialFunction.hxx
 File which defines the TensorialFunction class, a function which owns its values and returns them as TFEL's tensorial objects, and the aliases for the most common tensorial functions.
 
 TensorialFunction.ixx
 File which contains the implementation of the TensorialFunction class declared in MGIS/Function/TFEL/TensorialFunction.hxx.
 
 TensorModifier.hxx
 File which defines the TensorModifier class, an evaluator returning the values computed by an evaluator as TFEL's tensorial objects.
 
 TensorModifier.ixx
 File which contains the implementation of the TensorModifier class declared in MGIS/Function/TFEL/TensorModifier.hxx.
 
 TensorOperations.hxx
 File which declares functions rotating the tensorial values of a function into another basis and returning the result as a new function.
 
 Tensors.hxx
 File which defines the modifiers turning scalar valued functions and evaluators into tensor valued ones (as_stensor, as_tensor, ...) together with the tensorial operations which can be applied to evaluators (trace, det, eigen_values, rotate, logarithmic_strain, ...) and the concepts characterising evaluators returning the various kinds of tensorial objects.
 
 Tensors.ixx
 Implementation of the tensor modifiers and of the customization points used to reduce tensorial values computed by evaluators, declared in MGIS/Function/TFEL/Tensors.hxx.
 
 TensorView.hxx
 File which declares the TensorView class, an evaluator returning the values of a function as TFEL's tensorial objects.
 
 TensorView.ixx
 File which contains the implementation of the TensorView class declared in MGIS/Function/TFEL/TensorView.hxx.
