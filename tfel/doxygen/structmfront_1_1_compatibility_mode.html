Detailed Description

struct describing the various compatibility modes available

Compatibility modes are made for introducing breaking changes in the results or in the behaviour of MFront. Two examples motivated the introduction of this concept:

  • the modification of the values defined in the PhysicalConstants library to be more accurate and up-to-date.
  • the evolution of the PowellDogLeg algorithms to a more robust and classical version.

Those evolutions do not correct bugs, but changes the default MFront's behaviour and the results of the generated code for the better. Compatibility modes are meant to restore the behaviour of previous versions when needed for backward compatibility.

Note that such evolutions of the default MFront's behaviour shall only be tolerated on major versions. To be able to use such evolutions in the current version for testing and/or anticipating changes, the future compatibility mode allows changes that will be the default in the next major version.

Compatibility modes can be defined globally on the command line using --default-compatibility-mode or in a file using the compatibility_mode DSL option.
