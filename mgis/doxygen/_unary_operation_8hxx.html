Detailed Description

This file declares the UnaryOperation and UnaryOperation2 classes, which build a new evaluator by applying a unary operation to the values returned by an existing evaluator, the unary_operation and transform functions used to build such evaluators, the customization points used to implement unary operations on the supported result types and the predefined modifiers absolute_value, maximum_component, minimum_component, negate, multiply_by_scalar and divide_by_scalar.

modifier returning the absolute value of the values returned by an evaluator, as in e | absolute_value
