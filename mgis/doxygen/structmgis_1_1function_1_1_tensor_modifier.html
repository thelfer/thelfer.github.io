struct mgis::function::TensorModifier< TensorType, EvaluatorType >

an evaluator returning the values computed by an evaluator as TFEL's tensorial objects

The modifier is built from an evaluator whose number of components must be compatible with the tensorial type TensorType. Its call operators pass the value computed by the evaluator at a given integration point to the apply member function, which returns it as a tensorial object: a read-only tensor viewing the computed values if they are stored in memory owned by another object, a tensor owning a copy of these values otherwise.

Only the call operators which match the way the underlying evaluator can be called are available.
