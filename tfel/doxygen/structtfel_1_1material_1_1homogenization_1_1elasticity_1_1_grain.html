Detailed Description

template<tfel::math::ScalarConcept StressType>
requires (tfel::math::checkUnitCompatibility<tfel::math::unit::Stress, StressType>())
struct tfel::material::homogenization::elasticity::Grain< StressType >

This struct represents a grain of a polycrystal, as a child of class Phase. It contains an inclusion and also the attributes of Phase. It also has a method, computeMeanLocalisator, which returns the mean localisator of the grain, for a given matrix elasticity in parameter.
