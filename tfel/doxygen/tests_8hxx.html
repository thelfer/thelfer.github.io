Detailed Description

This file implements the tests of the semantics of the functions generated by the generic-parallel interface for material properties, shared by the tests of all the backends whose arrays are accessible by the host.

The test of a backend includes this file after the headers of the material properties and defines:

  • test_vector<T>, an array of values accessible by the host and by the device;
  • testExecution(), a function returning the execution of a synchronous evaluation (TestExecution): no statistics, and the execution policy of the tests (null for the default policy, queue of the tests with the sycl backend);
  • makeTestPolicy(o), a function returning an execution policy of the backend with the common options o, on the queue of the tests;
  • the MFRONT_GPMP_TEST_BACKEND_NAME macro, giving the name of the backend.
